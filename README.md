# JSON Runtime Renderer

## Overview
A dynamic UI rendering system powered by JSON configuration.

## Features
- Dynamic component rendering
- Form rendering
- Table rendering
- Unknown component handling
- Crash-safe UI
- Zod validation

## Supported Components
- heading
- form
- table

## How it works
JSON → Validation → Renderer → UI

## Run project
```
npm install
npm run dev
```

## Deployment
Deployable on Vercel
